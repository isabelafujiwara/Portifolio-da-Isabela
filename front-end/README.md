# Capacitação
  Dentro da Ecomp, Empresa júnior de Computação da UFPR, que eu participo desde o início de 2026, todos os membros recebem uma capacitação em uma determinada área relacionada ao desenvolvimento de sites, sistemas web, e outros serviços ofertados pela empresa. 
 
  Com isso, escolhi aprender a carreira de front-end.

  O processo de capacitação é desenvolvido no período de um mês, com aulas ministradas por outros membros da Ecomp que já conhecem o assunto, e no final os alunos entregam um projeto final envolvendo todos os assuntos estudados ao longo das aulas. Esse projeto, bem como as atividades semanais de fixação, são avaliados por outros membros mais experientes na carreira escolhida, e ao final eles dão o veredito se estamos aptos ou não a participar do desenvolvimento de projetos reais na empresa.

  Com o fim da minha capacitação eu fui certicicada como devidamente capacitada em front-end, tanto que já estou fazendo parte do desenvolvimento de projetos na empresa.

  Esse foi meu projeto final da capacitação.

  Recebemos um modelo pronto com todos os arquivos necessários e cada aluno foi modificando seus conteúdos para criar seu prórprio site, sobre qualquer assunto que quisesse. No meu caso, escolhi fazer um site sobre livros, que é um tópico que eu gosto muito!


# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
